## 목적

학생의 **5등급제 내신 등급**을 입력하면 **환산 9등급 성적**으로 바꾸고, 2026학년도 입결(70% cut)이 그 근처인 모집단위를 나열한다. 엑셀 `결과시트`의 동작을 웹앱으로 재현하고, 상담에 필요한 범위 조절·필터·정렬을 더한다. 학원·상담용.

## 원본 분석 결과

- `2026학년도 입결`: 14,612행. 열 = 지역, 대학명, 중심전형(교과/종합), 전형명, 계열(공통/예체능/인문/자연), 모집단위, 모집인원, 경쟁률, 충원순위, 70% cut. cut은 전부 숫자.
- `결과시트`
  - C1(노란 셀) = 5등급제 등급 입력(예 1.1). C2 = 환산 9등급 성적(1.39). T2:U396 = 변환표 395쌍(5등급 값 오름차순 1.00~5.00 → 9등급 값 1.24~8.97, 비감소).
  - E1 `=C2-0.1`, E2 `=C2+0.1`. 라벨은 "위로 0.2 / 아래로 0.2"이지만 실제 수식은 ±0.1.
  - J3:S = `E1 < cut < E2`(양끝 미포함) 인 입결 행을 **대학명 오름차순**으로 나열. 입력 1.1 → 1.29~1.49 → 259행. 이 규칙으로 259행이 정확히 재현됨(양끝 포함이면 280행으로 불일치).

## 계산 로직 (src/engine.js)

```js
convert(g5, pairs)       // g5 < 1.00 또는 > 5.00 또는 NaN → null. 아니면 pairs에서 g5 이하의 최대 키의 값.
searchRange(conv, down, up) // { lo: conv - down, hi: conv + up } (소수 셋째자리 반올림으로 부동소수 오차 제거)
search(rows, lo, hi)     // rows.filter(r => lo < r[9] && r[9] < hi)
applyFilters(rows, { regions:Set, type:''|'교과'|'종합', track:''|계열 })
sortRows(rows, colIndex, dir)  // 문자열은 localeCompare('ko'), 숫자는 수치 비교, null은 항상 마지막
```
- 부동소수: `1.39-0.1 = 1.2899999`처럼 되므로 lo/hi는 `Math.round(x*1000)/1000`로 정리한 뒤 비교. 골든 259행이 그대로 나와야 한다.
- 함수는 DOM을 모른다. `index.html`이 이 함수들을 조합한다.
